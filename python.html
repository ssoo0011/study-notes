01

변수와 자료형: 값에 이름 붙이기

변수는 값을 담는 상자라기보다 객체를 가리키는 이름이라고 생각하면 좋아요. Python은 대입된 값으로 자료형을 결정하며, type()으로 현재 값의 타입을 확인할 수 있습니다.

변수와 형 변환
count = 3
price = 2.5
name = "민지"
is_ready = True

number = int("12")
message = str(count)
print(type(price).__name__)  # float
자료형예시주요 특징
int7정수. 크기 제한 없이 정수를 표현해요.
float3.14실수의 근삿값. 소수 비교에는 오차가 있을 수 있어요.
str"hello"문자열. 작은따옴표나 큰따옴표를 사용해요.
boolTrue참 또는 거짓. 첫 글자를 대문자로 써요.
NoneTypeNone아직 값이 없거나 결과가 없음을 나타내요.

연산자와 값 비교

+, -, *는 기본 산술 연산이고 /는 실수 나눗셈, //는 몫, %는 나머지, **는 거듭제곱이에요. 비교 결과는 불리언으로 나옵니다.

연산 결과 읽기
print(7 / 2)          # 3.5
print(7 // 2, 7 % 2)  # 3 1
print(2 ** 3)         # 8
print(3 < 5 and 5 < 8)  # True

주의할 점 =는 대입, ==는 값 비교예요. is는 같은 객체인지 비교할 때 사용하고, 일반적인 값 비교에는 ==를 씁니다.

02

조건과 반복: 실행 흐름 제어하기

조건문은 참·거짓에 따라 실행할 코드를 선택하고, 반복문은 같은 작업을 여러 번 수행해요. Python에서는 들여쓰기가 코드 블록을 구분하므로 같은 블록의 줄을 같은 깊이로 맞춥니다.

조건에 따라 분기
score = 82
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
else:
    grade = "C"
print(grade)  # B

for와 while

for는 문자열이나 리스트처럼 순회할 수 있는 값에서 원소를 하나씩 꺼내요. range(start, stop, step)은 stop 직전까지 숫자를 만듭니다. while은 조건이 참인 동안 반복하므로 조건을 바꾸지 않으면 끝나지 않을 수 있어요.

누적 합과 반복 범위
total = 0
for number in range(1, 5):
    total += number
print(total)  # 10: 1 + 2 + 3 + 4
문장역할사용 예
break가장 안쪽 반복문을 끝냄찾는 값을 발견했을 때 종료
continue이번 회차의 나머지를 건너뜀특정 값을 처리하지 않을 때
pass아무 동작도 하지 않는 자리 표시나중에 구현할 코드 블록
03

문자열과 컬렉션: 여러 값을 다루기

문자열은 문자들의 순서 있는 묶음이고, 리스트·튜플·세트·딕셔너리는 여러 데이터를 저장하는 자료구조예요. 각 구조가 보장하는 순서와 변경 가능 여부를 구분해 선택합니다.

자료구조순서변경주요 사용
list있음가능순서 있는 값 모음, 추가·삭제
tuple있음불가바뀌지 않아야 하는 여러 값
set인덱스 순서 없음가능중복 제거, 포함 여부 확인
dict키와 값의 대응가능이름표(key)로 값(value) 찾기
인덱스, 슬라이스, 딕셔너리
colors = ["red", "green", "blue"]
print(colors[0])       # red
print(colors[1:3])     # ['green', 'blue']
colors.append("white")

user = {"name": "민지", "age": 20}
print(user["name"])    # 민지

인덱스는 0부터 시작하고 음수 인덱스는 뒤에서부터 세요. 슬라이스의 끝 인덱스는 결과에 포함되지 않습니다. 딕셔너리에 없는 키를 대괄호로 조회하면 KeyError가 날 수 있어요.

복사와 별칭

리스트 같은 변경 가능한 객체를 다른 변수에 대입하면 같은 객체를 함께 가리킬 수 있어요. 한쪽에서 내용을 바꾸면 다른 쪽에서도 바뀐 것처럼 보입니다.

같은 리스트를 가리키는 두 이름
first = [1, 2]
second = first
second.append(3)
print(first)  # [1, 2, 3]

별도 리스트가 필요하다면 first.copy()처럼 얕은 복사를 사용해요. 내부에 또 변경 가능한 객체가 있을 때는 얕은 복사와 깊은 복사의 차이도 살펴야 합니다.

04

함수와 변수 범위: 일을 작게 나누기

함수는 이름 붙인 작업 단위예요. 입력은 매개변수로 받고 결과는 return으로 돌려줍니다. 반환문이 없으면 함수 결과는 None입니다.

매개변수와 반환값
def calculate_total(price, quantity=1):
    return price * quantity

one = calculate_total(1200)
many = calculate_total(1200, 3)
print(one, many)  # 1200 3600

함수를 호출할 때 전달한 값이 인수가 되고, 함수 정의에서 값을 받는 이름이 매개변수예요. 기본값은 선택적으로 전달할 값을 정합니다. 기본값으로 리스트처럼 변경 가능한 객체를 사용하면 호출 사이에 값이 공유될 수 있어 주의해야 합니다.

지역 변수와 반환

함수 안에서 만든 지역 변수는 기본적으로 그 함수 안에서만 사용할 수 있어요. 함수는 계산 결과를 출력하는 일과 반환하는 일을 구분해야 재사용하기 쉽습니다.

출력과 반환은 다릅니다
def double(value):
    result = value * 2
    return result

answer = double(4)
print(answer)  # 8
05

클래스와 객체: 데이터와 동작 묶기

클래스는 객체를 만들기 위한 설계도이고, 인스턴스는 그 설계도로 만든 객체예요. 속성은 객체의 상태를, 메서드는 객체가 할 수 있는 동작을 나타냅니다.

클래스와 인스턴스
class Counter:
    def __init__(self, start=0):
        self.value = start

    def increase(self):
        self.value += 1

counter = Counter(3)
counter.increase()
print(counter.value)  # 4

__init__은 인스턴스가 만들어질 때 초기 상태를 준비해요. self는 현재 인스턴스를 가리키므로 self.value는 그 객체의 속성입니다.

상속과 메서드 재정의

상속은 기존 클래스의 동작을 물려받아 확장하는 방법입니다. 자식 클래스에서 같은 이름의 메서드를 다시 정의하면 인스턴스의 실제 타입에 맞는 구현이 호출됩니다. 여러 타입을 같은 인터페이스로 사용할 수 있는 다형성과 연결돼요.

예외와 파일: 실패를 다루고 결과 저장하기

잘못된 입력이나 파일 문제는 실행 중 예외를 일으킬 수 있어요. try에서 문제가 생길 수 있는 코드를 실행하고, except에서 예상한 예외를 처리합니다.

예외 처리
text = "42"
try:
    value = int(text)
except ValueError:
    value = 0
print(value)  # 42

가능하면 모든 예외를 무조건 잡기보다 처리할 수 있는 구체적인 예외를 잡아 원인을 숨기지 않도록 해요. 파일은 with를 사용하면 작업이 끝난 뒤 자동으로 닫힙니다.

파일 안전하게 읽기
with open("memo.txt", encoding="utf-8") as file:
    content = file.read()
print(content)

작은 문제 해결 순서 입력과 원하는 출력을 확인하고, 필요한 값을 변수로 나눈 다음, 작은 예제로 실행 결과를 확인해 보세요. 오류가 나면 메시지의 예외 이름과 줄 번호부터 읽으면 원인을 좁히기 쉽습니다.

변수 대입은 객체 복사가 아닐 수 있어요

Python 변수는 객체를 가리키는 이름입니다. 리스트를 다른 변수에 대입하면 같은 리스트를 가리켜 한쪽의 변경이 다른 쪽에도 보일 수 있어요.

별칭과 얕은 복사
original = [10, 20]
alias = original
copied = original.copy()
alias.append(30)
print(original)  # [10, 20, 30]
print(copied)    # [10, 20]

copy()는 바깥 리스트를 새로 만들지만 중첩 리스트 안쪽 객체는 공유할 수 있습니다. 함수가 전달받은 가변 객체를 바꿀지도 살펴보세요.

자료형 구분 리스트·딕셔너리는 가변 객체이고 문자열·튜플은 불변 객체예요. 함수가 새 값을 반환할지 객체를 바꿀지 분명히 하면 부작용을 줄일 수 있습니다.

심화

반복 처리와 자원 관리를 Python답게 쓰기

제너레이터는 값을 필요할 때 하나씩 만들어요

이터레이터는 다음 값을 순서대로 내놓고, 제너레이터 함수는 yield로 값을 생성합니다. 큰 파일이나 입력을 한꺼번에 메모리에 올리지 않아도 돼요. 한 번 소비한 이터레이터는 다시 처음부터 순회할 수 없는 경우가 많으므로 여러 차례 사용할 자료인지 확인합니다.

with와 타입 힌트로 의도를 표현해요

with 문은 예외가 생겨도 파일 같은 자원을 정리합니다. 타입 힌트는 입력과 반환의 기대 형태를 편집기와 정적 분석기에 알려 주지만 실행 중 값을 자동 검증하지는 않습니다. 가상 환경과 의존성 목록으로 프로젝트 실행 조건을 관리하세요.

  • 함수가 전달받은 가변 객체를 바꾸는지 명확히 합니다.
  • 구체적인 예외를 처리하고 원래 원인을 보존합니다.
  • 시간·네트워크 의존 부분은 테스트에서 대체할 수 있게 설계합니다.
